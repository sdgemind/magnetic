# 物理实验门户

电磁学交互演示合集，包含一个综合实验室和七个独立的原版演示。可用于课堂展示和自主探索，支持电脑与手机浏览器。

纯静态网页，无需安装依赖或构建。

## 开始使用

下载完整项目后，用浏览器打开 **[index.html](index.html)**，选择想要进入的页面。也可以直接打开 **[lab.html](lab.html)** 进入综合实验室。

请保留项目的目录结构，不要只下载 HTML 文件；实验室还需要同目录的 CSS 和 JavaScript 文件。

## 有哪些实验

| 实验 | 探索内容 |
| --- | --- |
| 动态圆 | 平移圆、旋转圆与放缩圆中的轨迹关系 |
| 磁聚焦与磁发散 | 粒子束在磁场中的发散与汇聚 |
| 有界磁场中的带电粒子 | 改变磁场边界与入射条件，观察粒子运动 |
| 复合场中配速法 | 交叉电磁场中的运动分解与漂移 |
| 回旋加速器 | 电场加速与磁场偏转的配合 |
| 右手螺旋定则 | 电流方向与空间磁场方向的关系 |
| 通电螺线管磁场 | 电流、磁极与磁感线分布 |

综合实验室将这七个实验放在同一工作台中；门户中的“原版交互演示”可分别打开原始页面。

## 实验室操作

- **选择实验**：通过顶部标签切换模型。
- **调节参数**：使用滑块或数值输入框；手机上可点按参数标签，用“更多”展开完整设置。
- **观察运动**：使用“开始演示”“暂停演示”和“单步”；“恢复默认”重置当前实验。
- **调整画面**：使用缩放按钮、拖动画面或双指缩放，点击“全景”恢复完整范围。三维实验支持拖动旋转。
- **拖动对象**：部分实验可直接拖动画布上的圆点，调整入射点、挡板或磁场边界。
- **查看原理**：点击“原理 / 数据”查看当前模型说明和测量值。

使用浏览器后退可返回门户；电脑布局下也可点击实验室左上角的品牌链接返回。

## 发布到 GitHub Pages

1. 将站点文件提交到 GitHub 仓库。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择存放站点文件的分支，目录选择 **/(root)**，保存。
5. 等待部署完成，访问 Pages 提供的网址。

`index.html` 会作为网站首页。链接使用相对路径，支持 `https://用户名.github.io/仓库名/` 形式的项目站点。

站点需要保留这些文件：

```text
index.html
lab.html
portal.css
style.css
app.js
geometry-handles.js
models-optics.js
models-fields.js
models-space.js
original/          # 七个原版 HTML
```

**发布目录中的内容应全部视为公开文件。** `.gitignore` 只影响未跟踪文件，不是网站访问控制，也不会删除已经提交的文件或历史记录。不要向仓库提交密钥、环境变量或私人备份；公开仓库中的文件即使不出现在门户，也可以被下载。

## 使用 Caddy 托管（可选）

如果本地保留了 `Caddyfile`，先将其中的 `root` 改为站点的实际绝对路径，再使用已安装的 Caddy：

```sh
caddy validate --config ./Caddyfile --adapter caddyfile
caddy run --config ./Caddyfile --adapter caddyfile
```

默认访问地址为 `http://localhost:8080/`。端口被占用时，可修改配置中的 `:8080`。

本地配置采用精确路径白名单；新增页面或资源时，需要同步更新。站点目录应只允许管理员修改，不要放入指向敏感文件的符号链接。`Caddyfile` 已加入 Git 忽略规则，不一定包含在克隆或下载的仓库中。GitHub Pages 不使用此配置。

## 使用须知

- 综合实验室与门户不依赖外部字体或脚本，可在本地使用。
- 部分原版页面仍引用在线资源：回旋加速器的公式排版使用外部 MathJax，有界磁场页面使用在线字体；离线时这些资源可能无法加载。
- 实验采用理想化物理模型，单位、方向约定和适用条件请参阅各实验的原理说明；画布尺寸不代表实际装置尺寸。
